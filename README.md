# laptop-secure-boot-investigation

一台 COLORFUL P16 Pro 的安全启动排查记录。**问题尚未解决，根因尚未确定。** 首页只汇总做过什么、观察到什么以及证据缺口，不给原因排优先级。

最新实测：[2026-10-07：COLORFUL 本机管理员只读复查](docs/INVESTIGATION-2026-10-07.md)。用户确认关闭安全启动后可正常启动；本次成功读取当前／默认数据库，核实当前 ESP 文件的内嵌签名与完整 PE 摘要，并将 4 种手工允许哈希对应到实际文件。没有新的 ON 启动测试。

此前安装 U 盘实测：[2026-10-06：ASUS 台式机上的 USB 检查](docs/USB-CHECK-2026-10-06.md)。该次 G: 默认入口是单一 2011 签名，仍未确认与旧 USB 测试的身份及内容连续一致。

此前 BIOS 现场记录：[2026-10-06：清除、恢复默认与手工信任测试](docs/INVESTIGATION-2026-10-06.md)。接手前阅读 [AGENTS.md](AGENTS.md) 和 [CLI-HANDOFF.txt](CLI-HANDOFF.txt)，区分历史操作与当前测量。

## 操作与结果

| 阶段 | 实际操作／检查 | 已记录结果 | 证据边界 |
|---|---|---|---|
| 10-05 Windows／USB 对照 | 分别关闭、开启安全启动；用户报告已重装过 Windows | 关闭时 Windows 与该安装 USB 可启动；开启时失败；重装未解决所述问题 | 旧 USB 的入口、签名与制作链未完整固定；不扩大为所有 USB 均失败 |
| 10-04 管理员静态检查 | 读取当时启动项、文件、数据库和日志 | 当时路径对应、所查签名／摘要通过、未匹配当时 dbx | 当前系统与分区布局有差异；保留为历史测量 |
| 10-06 USB 静态检查 | 在另一台 ASUS 台式机读取 G: FAT32 USB | 默认入口和根目录 bootmgr.efi 均仅有 2011 签名 | BCD 读取拒绝；未检查完整 boot.wim 链或新做启动对照 |
| 10-06 清除设置 | Erase all Secure Boot Settings 后保存重启 | 照片显示 Unlocked、Disabled、YES、Enforce 灰色 | 当时没有逐项导出空库或读取 SetupMode |
| 10-06 恢复默认并测试 | 按 Restore 流程恢复；用户报告自动开启 | 照片显示 Windows Boot Manager boot failed；DB 仍有 7 个名称 | 当时仅有名称；10-07 当前默认比较不能倒推恢复前后全部状态 |
| 10-06 手工信任与追加 | 信任主启动器及更多文件，重试 | 可见 7 条新增 SHA256；用户报告仍失败 | 当时摘要截断、映射不完整；没有最后一次新的错误画面 |
| 10-07 最新状态 | 用户反馈＋管理员读取 | 关闭时可正常启动；Confirm=False；SecureBoot=00、SetupMode=00 | 没有新的 ON 测试或返回码 |
| 10-07 当前／默认数据库 | 导出并完整解析当前及默认变量 | PK、KEK、dbx 分别等于当前默认值；db 为默认 7 张证书加 7 条 SHA256 | 只比较本次变量；不是整个固件恢复证明或前次操作快照 |
| 10-07 文件与条目核对 | 读取当前 ESP、BCD 目标、10 个 EFI 路径，验证内嵌签名与 PE 摘要 | 主／备用为 2023 内嵌签名；5 个 ESP 路径对应 4 种允许摘要；所查文件未命中当前 416 条 dbx 摘要 | 其余 3 条允许摘要尚未映射；没有完整启动链或固件执行跟踪 |

**这些操作和静态结果仍不足以确定根因，不能写成“已经证明 BIOS 有 bug”“所有启动环节都已排除”或“固件在 ON 状态已经放行”。**

## 最近状态与未完成事项

当前实测安全启动关闭、PK 已安装；用户确认关闭后可正常启动。当前 db 的 7 条手工哈希仍在。10-07 成功取得原始数据库、当前默认比较和部分完整文件映射，不再把这些全部列为从未检查。

当前 Windows 为 26300.9457（26H2），唯一可枚举 ESP 为 Disk 0 Partition 1、200 MiB；10-04 是 26200.9457、Partition 2、100 MiB。变更时间与原因未核实，不默认旧启动项或旧备份仍对应现在。

尚缺新的 ON 状态失败返回码／执行跟踪、其余 3 条允许哈希映射、原始 BootCurrent／Boot#### 和完整后续策略检查，以及旧 USB 身份连续性与明确签名的介质启动配对。前次清除阶段空库证明和恢复前后完整快照仍缺失；当前变量比较不能回填。

Win10 安装 U 盘对照、恢复工具、刷 BIOS 的历史讨论仍不等于执行结果。本次没有运行修复、改密钥或重启。

## 设备识别

本次 CIM 确认为 COLORFUL P16 Pro、INSYDE BIOS `1.07.05COLO3`（日期 2025-08-14）。历史记录的 i9-13900HX、16 GB、KBC/EC `1.09.04CF1`、ME `16.1.32.2473` 未在本轮全部重读；准确子型号与固件包适用性仍需独立核实。不能只凭系列名选刷写包。

10-06 BIOS 照片日期显示 2026/10/07，旧记录按当时对话日期命名；时钟与时区未校准，不据此诊断故障。10-07 实测时间明确记录 UTC+08:00。
