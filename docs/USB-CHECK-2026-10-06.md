## 检查方法、错误与未完成部分

主要只读命令如下（G:、Disk 2 仅对应本次实测对象，后续须重新枚举）：

```powershell
Get-CimInstance Win32_ComputerSystem | Select-Object Manufacturer, Model
Get-Disk
Get-Volume
Get-Partition -DiskNumber 2
Get-ChildItem -LiteralPath 'G:\' -Filter '*.efi' -Recurse -File
Get-AuthenticodeSignature -LiteralPath 'G:\efi\boot\bootx64.efi'
Get-FileHash -LiteralPath 'G:\efi\boot\bootx64.efi' -Algorithm SHA256
bcdedit /store G:\efi\microsoft\boot\BCD /enum all
```

最后一条 BCD 命令未成功，原始错误为：

```text
The boot configuration data store could not be opened.
Access is denied.
```

该命令退出码为 1。保留为读取失败，不记成 BCD 不存在、损坏或配置已验证。当前非管理员 token 已另行确认，但没有重试提权以查明全部原因。

本次没有挂载或解包 boot.wim / install.swm，没有检查 WinPE 内的 winload.efi、内核及完整后续启动链，没有完整介质哈希或原始 ISO 官方哈希比对。Windows Authenticode 的 Valid 是当前台式机的静态检查结果，不替代笔记本固件 db/dbx、策略及实际执行验证。

本次没有启动该 U 盘，没有新的 Secure Boot OFF/ON 对照，没有重新读取 COLORFUL 的固件变量，也没有写入 U 盘、格式化、修改 EFI 文件、运行恢复程序、修改密钥、重启或重装。

## 对已有测试的意义与限制

1. **新实测事实：**当前这只 U 盘的默认 UEFI 启动器是单一 2011 签名。不能由“它是 Win11 安装盘”推断它是 2023 签名盘。
2. **历史关联尚未确认：**此前 10-05 用户报告安装 USB 关闭安全启动可启动、开启失败。如果用户确认当时就是当前这只盘、期间没有改写，当前签名测量才能为该历史对照补充证据；现在不自动认定身份与内容连续一致。
3. **内置 2023 是另一对象：**10-04 报告记录过 SSD 实际 bootmgfw.efi 为 Windows UEFI CA 2023 签名。这是历史测量；本轮没有重测笔记本，也不是“2023 安装 USB 已测试”的证据。
4. **仍缺明确的介质配对测试：**没有对同一安装介质的 2011 / 2023 两版完成签名核实与实际启动对照。不能写成“所有 2011 / 2023 程序均不能启动”，也不能据此确定 BIOS 缺陷或撤销规则就是根因。
5. 本轮静态检查只增加证据；故障根因仍未确定。
